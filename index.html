Como decidir a tag

Uma linha em SPLIT_ERROS, sozinha, não define o estado atual.

Precedência crítica: erro tipo 2 pode aparecer depois da liquidação; erro antigo tipo 1 não deve encobrir um Split concluído; tipo 3 é indisponibilidade.

SQL mínimo

SELECT ID_RECEBIMENTO_RECB, FL_STATUS_RECB, ID_SPLIT_RECB
FROM RECEBIMENTO WHERE ID_RECEBIMENTO_RECB = :id;

SELECT ID_SPLIT_SPL, ID_REPASSE_REP, FL_STATUS_SPL, VL_SPLIT_SPL
FROM SPLIT WHERE ID_RECEBIMENTO_RECB = :id;

SELECT ID_SPLITERRO_SPE, FL_TIPOERRO_SPE, ST_CATEGORIA_SPE,
       ST_DESCERRO_SPE, DT_ERRO_SPE
FROM SPLIT_ERROS
WHERE ID_RECEBIMENTO_RECB = :id
ORDER BY ID_SPLITERRO_SPE DESC;
